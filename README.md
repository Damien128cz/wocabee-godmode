# 🚀 Wocabee GodMode

Tento projekt slouží jako pomocník pro studium slovíček na platformě Wocabee. Kombinuje sílu Tampermonkey pro automatické překlady a AutoHotkey pro simulaci skutečného psaní.

## 🛠️ Funkce
- **Automatické překlady:** Okamžitě najde odpověď na otázku.
- **Vlastní slovník:** Možnost opravit překlad a uložit si ho do paměti (verze učitele).
- **Ghost Mode:** Schování menu pomocí klávesy `;`.
- **Auto-Type (F2):** Simulace lidského psaní pomocí AutoHotkey, aby systém nepoznal bota.
- **Export/Import:** Možnost přenášet zapamatovaná slovíčka mezi počítači.

## 📦 Instalace

### 1. Prohlizeč (Tampermonkey)
1. Nainstaluj si rozšíření **Tampermonkey**.
2. Vytvoř nový skript a vlož do něj kód z souboru `WocabeeHelper.user.js`.
3. Ulož skript a obnov stránku Wocabee.

### 2. Windows (AutoHotkey)
1. Nainstaluj si **AutoHotkey v2.0**.
2. Stáhni soubor `WocabeeBot.ahk` a spusť ho dvojklikem.
3. V pravém dolním rohu by měla být zelená ikona "H".

## 🎮 Jak to používat
1. V boxu vlevo dole klikni na tlačítko **KOPÍROVAT**.
2. Klikni myší do políčka pro odpověď ve Wocabee.
3. Stiskni klávesu **F2** na klávesnici.
4. Odpověď se sama "vyťuká" do políčka.
